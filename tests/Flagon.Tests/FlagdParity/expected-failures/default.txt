# (DefaultCompilerParityTests). One case id per line (<feature path>:<line>); text after '#' is a comment.
#
# The list is exact: a listed case that passes fails the run. It must be empty once the chosen targeting engine is
# the default.
#
# Why these fail today: the default compiler is NullTargetingCompiler, whose rules never match, so every targeted flag
# serves its defaultVariant with reason DEFAULT. Every case expecting a rule match (TARGETING_MATCH, fractional
# buckets, sem_ver/starts_with/ends_with hits, $ref and $flagd.* rules), a PARSE_ERROR for a bad rule, or a GENERAL
# error for an unknown variant fails.
#
# Also failing independently of the compiler: cases whose flag has a null or absent defaultVariant (flagd allows this;
# Flagon's FlagDocument requires one, so FlagdJson rejects the fixture and the flag is missing from the store). They
# are marked "(fixture flag not storable ...)" below.
